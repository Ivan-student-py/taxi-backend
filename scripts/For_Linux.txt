В терминале WSL:
1) Клонировать репозиторий (если нужно)
git clone <your-repo-url> ~/taxi-backend
cd ~/taxi-backend

2) Убедиться, что зависимости установлены
./mvnw clean compile  # или mvn clean compile

3) Запустить приложение (в фоне)
./mvnw spring-boot:run &

4) Дождаться старта (можно проверить порт)
sleep 10
curl -s http://127.0.0.1:8080/actuator/health || echo "App starting..."

5) Протестировать скрипты
./scripts/register-passenger.sh
./scripts/register-driver.sh
./scripts/login.sh
./scripts/get-passenger.sh 2
./scripts/update-driver-status.sh 1 BUSY

6) Проверить БД (если pgAdmin недоступен)
sudo -u postgres psql -d taxi_db -c "SELECT id, email FROM passengers;"

1. Сделать скрипты исполняемыми (в WSL):
chmod +x scripts/*.sh

2. Установить jq (для красивого вывода JSON) в WSL:
sudo apt update && sudo apt install -y jq
